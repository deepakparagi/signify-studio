## 📌 About

Signify Studio empowers users to create professional-grade digital signatures without requiring complex design software. By leveraging the native HTML5 Canvas API, the application provides a zero-latency drawing experience that responds flawlessly to both mouse and touch inputs across all devices.

The architecture is strictly client-side, meaning no data is ever transmitted to a server. Signatures are managed securely via browser `localStorage` and can be exported instantly as high-quality PNGs with transparent or custom backgrounds.

| Feature | Description |

## 🚀 Getting Started

### Prerequisites

Signify Studio requires **no build tools**, Node.js, or server environments. It runs entirely in the browser.

### Installation & Execution

```bash
# 1. Clone the repository
git clone https://github.com/deepakparagi/signify-studio.git

# 2. Navigate into the project
cd signify-studio

# 3. Open index.html in any modern browser
# You can double-click the file, or use a local server like Live Server (VS Code)
```

---

## 💻 Usage Guide

1. **Draw:** Use your mouse, trackpad, or touchscreen to draw your signature in the main canvas area.
2. **Customize:** Utilize the toolbar to change brush color, adjust stroke thickness, or set a background color.
3. **Save/Retrieve:** Click **Save** to store your current signature in local memory. Click **Retrieve** to load it back later.
4. **Export:** Click **Download** to generate a transparent PNG file of your signature for use in documents, emails, or PDFs.
